; 4. Translate this C statement into an assembly program. 16-bit signed integers
;    x, y, and z are stored in 32-bit registers r0, r1, and r2, respectively.
;    x = x * y + z - x;

SXTH r3, r0
SXTH r4, r1
SXTH r5, r2       ; sign extension possibly unnecessary
MLA r6, r3, r4, r5
SUBS r7, r6, r3   ; wrong, answer should be stored in x at r0


; 5. Translate this C statement into an assembly program, assuming 16-bit un-
;    signed integers x and y are stored in register r0, and r1, respectively.
;    x = x % y;

UXTH r2, r0 ; x
UXTH r3, r1 ; y
UDIV r4, r2, r3 ; floor
UMUL r5, r3, r4 ; floor * y
SUB r0, r2, r5


; 6. Write an assembly program that calculates this polynomial, assuming signed
;    integers x and y are stored in r0, and r1, respectively.
;    y = 3x^3 - 7x^2 + 10x - 11

MUL r2, r0, r0      ; r2 = x^2
MOV r3, #3          ; r3 = 3
MOV r4, #7          ; r4 = 7
MOV r5, #10         ; r5 = 10
MUL r6, r0, r2      ; r6 = x^3
MUL r3, r3, r6      ; r3 = 3x^3
MLS r3, r2, r4, r3  ; r3 = 3x^3 - 7x^2
MLA r3, r5, r0, r3  ; r3 = 3x^3 - 7x^2 + 10x
SUBS r1, r3, #11    ; r1 = 3x^3 - 7x^2 + 10x - 11

; 7. Write an assembly program that calculates the remainder of the division 
;    between two unsigned 32-bit integers.

LDR r0, =a          ; r0 = a = 19
LDR r1, =b					; r1 = b =  7
LDR r2, =r					; r2 = r
UDIV r3, r0, r1     ; r3 = a / b = 19 / 7
MLS r2, r3, r1, r0  ; r2 = 19 - 14 = 5
STR r2, [r3]

; 8. Explain why Cortex-M processors do not provide any left rotation instruci-
;    tions. They only offer ROR (rotate right) and RRX (rotate right extended).

A rotate left instruction by n-bits can just be performed with a rotate right
by 32 - n bits.

; 9. Explain the difference between the Barrel shifter's role in the following
		 instructions:
			(1) ANDS rl, r2, r3, LSL #3
			(2) ADDS rl, r2, r3, LSL #3

The Barrel shifter will shift r3 3 bits to the left before performing ANDS
against r2, and the barrel shifter will do the same with ADDS in the same order.

; 10. Write an assembly program that reverses the byte order of a register with-
out using the REV instruction.

LDR r0, =data
LDR r1, [r0]
UBFX r2, r1, #0, #8    ; first byte extracted
UBFX r3, r1, #8, #8    ; second byte extracted
UBFX r4, r1, #16, #8   ; third byte extracted
UBFX r5, r1, #24, #8   ; forth byte extracted
ORR r6, r2, r1, LSL #8 ; shift a byte left, insert second byte
ORR r6, r3, r1, LSL #8 ; shift a byte left, insert third byte
ORR r6, r4, r1, LSL #8 ; shift a byte left, insert fourth byte
STR r1, [r0]
